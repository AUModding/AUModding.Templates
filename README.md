# AUModding.Templates
https://www.nuget.org/packages/AUModding.Templates

This repository contains various templates for various APIs which allow you to get started quickly on your next AU Project.

To get started, do `dotnet new install AUModding.Templates`

### Minimal
Usage: `dotnet new aumodding.minimal -n (name)`

A minimal template which does not include any APIs outside of BepInEx.

### Reactor
Usage: `dotnet new aumodding.reactor -n (name)`

A template which has Reactor preinstalled and some minimal things configured for you.

Credits: [Daemon](https://github.com/DaemonBeast/Reactor.Template)

### MiraAPI
Usage: `dotnet new aumodding.miraapi -n (name)`

A template which has MiraAPI preinstalled and some minimal things configured for you.

Credits: [AllOfUs](https://github.com/All-Of-Us-Mods/MiraAPI/tree/master/MiraAPI.Example)
